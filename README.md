# 🎵 TuneFlow

A modern and responsive music player built with **HTML, CSS, and JavaScript**.

### ✨ Features

* ▶️ Play / Pause
* ⏮ Previous / Next
* 🎚️ Progress bar
* 🔊 Volume control
* 📱 Responsive design
* 🎵 Multiple playlists
